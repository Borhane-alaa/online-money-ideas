# online-money-ideas

Curated research vault: legitimate ways to make money online that can be
automated (or significantly accelerated) with code. Built to filter signal from
the noise — every idea here is either something I have personally validated or
that comes from a credible primary source (payment processor docs, marketplace
docs, named creator, audited revenue disclosure).

This is **not** a get-rich-quick notebook. It is a deliberate, evidence-first
inventory of code-leveraged income paths so I (and you) can pick one with eyes
open instead of chasing the next shiny thing.

## Scope rules

An idea qualifies only if it satisfies all four:

1. **Legit** — real demand, real buyers, real payment. No dropshipping guru
   funnels, no MLMs, no "traffic Arbitrage Secrets" courses, no crypto-Ponzi
   tokens, no fake-engagement-for-sale.
3. **Code-automatable** — at least 60 % of the work (research, content
   generation, ops, fulfillment, monitoring) can be done by code the operator
   wrote or wired together. Pure service hours don't qualify.
4. **Solo-friendly** — one person can realistically run it (with help of code),
   without hiring a team or burning $10k+ on ads before validating.
5. **Reproducible** — someone else following the notes could plausibly reach
   $100/month. "I got lucky" stories don't count.

## How an idea is graded

Each idea file carries four scores (1–5, conservative):

- **effort** — how many hours/week to keep it alive once it's running
- **skill** — minimum technical bar to build v1 (3 = solid dev, 5 = senior+)
- **ceiling** — realistic monthly ceiling for one operator
- **risk** — 1 = near-zero (platform controls everything), 5 = regulatory /
  reputational / capital risk

A short verdict line follows: "ship now / validate next / back-burner / drop".

## How to use this vault

- I'm not committing to shipping every idea here. Most will die in the
  "validate next" or "drop" bucket. That's the point.
- If something stays in `back-burner` for 90+ days with no movement, delete it.
- If a `validate next` idea goes 30 days without code being written, downgrade
  it.
- Revenue numbers quoted are *realistic*, not influencer-floor-talk. When I see
  a creator claiming "$10k/month passive", I write down their niche, their
  spend, and whether they sold a course on the way there.
